# Apps

This directory contains the OrbitalOS application crates.

## Planned Apps

- [`drift/`](drift/README.md) Notes
- [`blink/`](blink/README.md) Snapshot
- `prism/` Viewer
- `vector/` Planner
- `relay/` Mail
- `control/` Settings
- `dock/` Files

## Current Status

`drift/` is the first app target for Phase 1.3 and will become the first GTK4 +
Libadwaita application built on top of `orbital-core`.

`blink/` is now in early Phase 1 and already has a persistent snapshot library
on top of the shared OrbitalOS core.

Current app docs:

- [`Drift README`](drift/README.md) for current features, setup, and run instructions
- [`Blink README`](blink/README.md) for current Phase 1 features, direction, and run instructions
