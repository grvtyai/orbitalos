# Apps

This directory contains the OrbitalOS application crates.

## Planned Apps

- `drift/` Notes
- `vlink/` Snapshot
- `prism/` Viewer
- `vector/` Planner
- `relay/` Mail
- `control/` Settings
- `dock/` Files

## Current Status

`drift/` is the first app target for Phase 1.3 and will become the first GTK4 +
Libadwaita application built on top of `orbital-core`.
